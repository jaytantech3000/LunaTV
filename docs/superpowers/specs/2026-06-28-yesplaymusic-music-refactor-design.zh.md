# LunaTV YesPlayMusic 音乐模块重构设计

**目标**

在不重写现有音频播放内核的前提下，按 YesPlayMusic 的页面结构、播放器语义和核心交互重构 LunaTV 音乐模块，交付一个可实际播放、切歌、排队、展示歌词、收藏和跨来源浏览的完整播放器系统。

**范围**

- 重构音乐页的信息架构与视觉层级，使其更接近 YesPlayMusic 的浏览路径
- 重构底部播放器，使其还原 YesPlayMusic 的三段式控制条
- 重构展开态播放器，使其具备封面、歌词、队列、音量、收藏、播放模式等完整能力
- 调整播放器状态模型，使其支持独立的重复模式与随机模式
- 保留现有多来源适配层、`audio` 元素播放链路和 `MusicPlayerRoot` 装配点
- 保持 Jamendo 等来源的可用性降级逻辑

**不做**

- 不直接复制 YesPlayMusic 源代码
- 不引入网易云登录、私人 FM、MV 等当前仓库没有后端依赖的能力
- 不重写 `MusicApi` provider 抽象
- 不替换为新的播放器库

**现状判断**

- 现有播放器已经可播，但底栏控件组织与 YesPlayMusic 差异很大
- 当前 `playMode` 把“循环”和“随机”揉在一个枚举里，难以复刻 YesPlayMusic 的独立按钮语义
- 音乐页当前是“Hero + Spotlight + 列表”的营销页结构，不是播放器产品的主导航结构
- 歌词和队列已存在，但没有形成统一的展开态交互

**目标架构**

1. `musicPlayerStore`

   - 把播放控制状态拆成：
     - `repeatMode: 'off' | 'all' | 'one'`
     - `shuffleEnabled: boolean`
   - 保留：
     - `queue`
     - `currentIndex`
     - `presentation`
     - `volume`
     - `muted`
     - `currentTimeSec`
     - `lyrics`
     - `streamUrl`
   - 队列切歌规则由 store 统一负责，UI 不直接推断下一首

2. `MusicPlayerRoot`

   - 继续作为唯一播放装配层
   - 负责：
     - 拉取当前曲目流地址与歌词
     - 管理 `audio` 生命周期
     - 收藏、最近播放、播放记录持久化
     - 控制展开态默认进入“歌词”还是“队列”

3. `MusicMiniPlayer`

   - 改成 YesPlayMusic 风格的底部固定控制条
   - 结构分三段：
     - 左侧：封面、歌名、歌手、收藏
     - 中间：上一首 / 播放暂停 / 下一首
     - 右侧：队列、重复、随机、音量、歌词展开、关闭
   - 进度条独立放在顶部细轨道

4. `MusicFullscreenPlayer`

   - 改成播放器主舞台，而不是大号控制卡片
   - 左区：
     - 封面
     - 曲目信息
     - 音量与收藏
     - 进度条
     - 主控制按钮
   - 右区：
     - 歌词视图
     - 队列视图
   - 通过页内 tab 在歌词 / 队列之间切换

5. `MusicPageClient`
   - 去掉营销化 Hero 文案，改成播放器产品页结构
   - 保留来源切换，但页面组织改为：
     - 顶部来源导航
     - 分区导航
     - 当前分区内容
     - 详情态集合头部 + 曲目表
   - 搜索、曲库、合集详情继续共用统一队列播放入口

**关键交互**

- 点击底栏“歌词”按钮：
  - 展开播放器
  - 默认进入歌词视图
- 点击底栏“队列”按钮：
  - 展开播放器
  - 默认进入队列视图
- 点击“重复”按钮：
  - `off -> all -> one -> off`
- 点击“随机”按钮：
  - 独立切换 `shuffleEnabled`
- 歌曲结束：
  - `repeatMode=one` 时重播当前曲目
  - `shuffleEnabled=true` 时随机切下一首
  - `repeatMode=off` 且已到队列末尾时停止播放
  - 其他情况按列表顺序切歌

**错误处理**

- 拉流失败：
  - 保留当前队列
  - 设置明确错误文案
  - 不清空播放器 UI
- 歌词失败：
  - 只让歌词区回退为空态
  - 不影响音频播放
- 来源不可用：
  - 继续沿用服务端 provider 降级
  - 前端只消费 `enabled` 结果

**测试策略**

- `musicPlayerStore`
  - 覆盖重复模式与随机模式的切歌规则
- `MusicMiniPlayer`
  - 覆盖队列按钮、歌词按钮、重复按钮、随机按钮、音量调整
- `MusicFullscreenPlayer`
  - 覆盖歌词 / 队列切换和主控制按钮
- `MusicPlayerRoot`
  - 覆盖展开态入口、音频结束后的切歌逻辑、收藏行为
- `MusicPageClient`
  - 覆盖分区浏览、合集播放、详情切换、搜索与曲库主路径

**验收标准**

- 底部播放器在视觉结构和交互语义上接近 YesPlayMusic
- 展开态播放器可稳定显示歌词和队列
- 播放器支持上一首、下一首、暂停、继续、拖动进度、音量、收藏、重复、随机
- 音乐页可以从来源首页、合集详情、搜索结果、曲库入口稳定启动播放
- 自动化测试通过
- `pnpm build` 与 beta 构建通过
